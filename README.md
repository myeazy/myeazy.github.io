# EAZY — ЕГЭ и ОГЭ без лишнего

Понятные разборы заданий ЕГЭ: короткая теория без воды, разбор примера, код для самопроверки и тренировка с мгновенной проверкой ответа — всё на одной странице.

**Сайт:** [myeazy.github.io](https://myeazy.github.io)

## Что внутри

- Каталог всех 27 заданий ЕГЭ по информатике — с темами, уровнем сложности и временем на чтение.
- Полные разборы с практикой и проверкой ответов. Готовые номера смотри в каталоге — новые добавляются постепенно.
- В каждом разборе: теория, алгоритм решения, разобранный пример, типичные ошибки, код на Python и тренировочные задачи с подсказками. Видеоразбор — там, где он есть.

## Почему это удобно

- Работает как приложение: устанавливается на телефон и открывается даже без интернета.
- Светлая и тёмная темы.
- Быстрый поиск по заданиям — Ctrl+K.
- Ответы к тренировке хранятся только в браузере: без регистрации, аккаунтов и сбора данных.
- Кнопка «Поделиться» открывает системный лист телефона — в сообщение уже подставлены номер задания и предмет.
- Бесплатно и без рекламы.

## Планы

Закрыть все 27 номеров по информатике, затем добавить другие предметы — математику, русский язык, физику — и раздел ОГЭ.

### Свой разбор — это просто

Разбор живёт в одном файле: `assets/tasks/<предмет>/NN.js` — теория, пример, код и задачи для тренировки. Метаданные номера — в `assets/tasks.js`: массив `TASKS.<предмет>` и флаг `ready: true`. Новый предмет включается одной строкой в `CATALOG` (поставить `active: true`). Страница `myeazy.github.io/task/?subject=<предмет>&id=NN` подхватывает разбор автоматически. Проверка перед пушем: `node --check assets/tasks/<предмет>/NN.js`.

### Версии и кеш

При изменении `styles.css`, `task.css`, `app.js`, `task.js`, `tasks.js` или `selects.js` поднимай версию в HTML (`?v=14` → выше) **и** имя кеша в `sw.js` (`eazy-v18` → выше) — иначе установленная PWA ещё до 10 минут покажет старую версию.
