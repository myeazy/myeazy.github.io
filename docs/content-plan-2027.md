# План контента EAZY — сверка с ЕГЭ-2027

## 1. Официальные изменения (ФИПИ, документ 2027)

Источник: `https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/Izmeneniya_KIM_EGE_2027.pdf`

| Предмет | Изменения 2027 |
|---|---|
| Информатика | Структура и содержание КИМ **без изменений**. Изменена только запись ответа №27: одна строка из двух чисел вместо двух строк |
| Математика (профиль) | **Изменений нет** |
| Математика (база) | Изменений нет |

**Вывод:** номера заданий, темы и формат разборов актуальны. Переделывать структуру каталога не нужно. Приоритет — информативность, а не «новые задания».

## 2. Что правим по отзывам

1. Полный разбор должен **объяснять, откуда берётся формула** (поле `derivation`).
2. Геометрия и схемы требуют **чертежей** (поле `figure` — в теории и в отдельных задачах тренажёра).

## 3. Новая структура полного разбора

| # | Блок | Что внутри |
|---|---|---|
| 01 | Зачем это на экзамене | что проверяют, где встречается, сколько времени закладывать |
| 02 | Теория без воды | суть в 2–3 абзаца |
| 03 | Чертёж-опора | SVG-схема фигуры/графа/маски |
| 04 | Формулы | карточки с формулами |
| 05 | Почему формулы работают | выводы с нуля (`derivation`) |
| 06 | Разбираем на примере | пошаговое решение |
| 07 | Ловушки | типичные ошибки с пояснением |
| 08 | Тренажёр | задачи с подсказками, часть — с чертежами |

Шпаргалка (режим «⚡») остаётся короткой: формулы → шаги → пример → ошибки → код.
